# RoykodanAADC - Eggspresi Cinta

Kuis interaktif Love Language "Eggspresi Cinta" kolaborasi Royco x Ada Apa Dengan Cinta (AADC).

## 🚀 Fitur Utama
- **6 Tahap Alur UI Interaktif**:
  1. **Intro Screen**: Maskot Telur & Brand Header Royco x AADC.
  2. **Lead Form**: Pengumpulan data peserta (Nama, WhatsApp, Email, Consent).
  3. **Ready Screen**: Sapaan personal *"Halo, {Nama}!"*.
  4. **Quiz Questions**: 5 pertanyaan otentik seputar masak telur & love language.
  5. **Loading Screen**: Animasi Canvas PNG Sequence wajan membalik omelet 36 FPS.
  6. **Result Screen**: Kartu Love Language resolusi tinggi, Slip Struk Thermal Siap Cetak, dan Live QR Code.
- **Halaman Khusus Penerima QR Code**: `/result/[token]` untuk menyimpan dan membagikan kartu cinta ke sosial media.
- **Tipografi Kustom**: Font resmi Isidora.

## 🛠️ Tech Stack
- **Framework**: Next.js 15 (App Router), React 19, TypeScript
- **Styling**: Tailwind CSS v4
- **Database / ORM**: SQLite & Prisma ORM
- **Icons & Animation**: Lucide React, Framer Motion, HTML5 Canvas Sequence

## 📦 Menjalankan Project
```bash
cd FE
npm install
npm run dev
```
